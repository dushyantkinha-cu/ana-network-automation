# Change Management Workflow

## 1. Purpose

All changes to the ANA Network Automation Framework are tracked using
Git and stored in the project's GitHub repository.

Git provides:

- Version history
- Change tracking
- Configuration rollback
- Accountability
- Reproducibility
- Comparison between versions

---

## 2. Repository

main

Remote:

origin
